# more funny color stuff but 8-bit
a blast back to the 80s or smth idk

> # Warning
> Just like CIMG, this project is not really meant to be used for very serious projects and yeah

BS (byte-size) Color is exactly what it says on the tin - a project which aims to make colors that fit in one byte (8-bits, which is where the term "8-bit graphics" comes from). It provides you with all the image tools you might need - cropping, resizing, image file I/O, 1 alpha color and other image editing stuff

Don't really know what else to say. Have fun I guess. Or don't. If you don't want to.
